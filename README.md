# Cadastro de Empresas

Evolução do desafio proposto para o curso de Desenvolvedor Mobile da Próz. Na primeira versão
desenvolvi um aplicativo que utilizava apenas o Terminal, disponível
em: https://github.com/pertusatti22/dart.desafio.Sistema-de-registro-de-empresas

Foi o primeiro desafio de código do curso, e suas instruções estão disponíveis em:
em: https://gist.github.com/DeyvidJLira/d429c2f8b7178b48215c86c90d4fb5f5

A partir da primeira MasterClass de User Interface do curso criei o seguinte design, que foi
utilizado como protótipo para o projeto:
https://www.figma.com/file/6B0YtMncg9jFrXkG2lQ3VB/Desafio-Flutter?node-id=0%3A1

## 🚀 Começando

Para executar o projeto basta executar um emulador de android e abrir sua pasta em um terminal e
digitar o comando:

> flutter run

### 🔧 Instalação

Para obter uma cópia do projeto basta realizar um Fork ou utilizar o comando:
> git clone "https://github.com/pertusatti22/sistemadecadastro.git"
